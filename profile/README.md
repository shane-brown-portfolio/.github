# Shane Brown – Software Engineering Portfolio

Software engineer building tools and systems across data processing, backend services, and low-level programming, from protocol demodulation to audio synthesis to AI-assisted route planning.

## Projects

**[RunAssistantMCP](https://github.com/shane-brown-portfolio/RunAssistantMCP)**: AI-powered assistant that generates walking/running routes with runtime estimates, using Google Maps, weather APIs, and Gemini 2.0 Flash.

**[lock-out](https://github.com/shane-brown-portfolio/lock-out)**: Area-capture arcade game (JezzBall-style) where you control a marble to claim territory while avoiding enemies.

**[arvik](https://github.com/shane-brown-portfolio/arvik)**: UNIX-style command-line file archiver built on low-level I/O system calls.

**[modem-demodulator](https://github.com/shane-brown-portfolio/modem-demodulator)**: Decodes audio signals using the Bell 103 modem protocol.

**[aleatoric](https://github.com/shane-brown-portfolio/aleatoric)**: Generative music tool that randomizes key, tempo, chord progression, and melody into a complete composition, synthesized with sawtooth waveforms and played live or rendered to WAV.

**[synth](https://github.com/shane-brown-portfolio/synth)**: Python MIDI synthesizer with sawtooth waveform synthesis and MIDI controller support.

**[sine-wave-audio-generator](https://github.com/shane-brown-portfolio/sine-wave-audio-generator)**: C++ sine wave generator with clipping and WAV file output.
